# 닥터빌 제안서 생성기 (drville-proposal)

제안처 정보와 요구사항 원문(RFP·메일·통화 메모)을 넣으면 LLM이 요구사항을 분석해
닥터빌 표준 템플릿 그대로 **웹브로셔(HTML)** 와 **PPT(16:9)** 제안서를 만듭니다.

- 사이트: https://doctorville.github.io/drville-proposal/
- 원문 데이터: 닥터빌 웹브로셔 + 닥터빌 광고제안서(2026.06)
- 운영: 엠서클 닥터빌 콘텐츠운영팀

## 사용 방법

1. 사이트를 열고 제안담당자·제안처·요구사항을 입력합니다.
2. 왼쪽 아래 **LLM 연결**에서 엔진을 고릅니다.
   - **Claude API**: Anthropic API 키(`sk-ant-...`)를 입력하고 `연결 확인 · 모델 불러오기`를 누릅니다.
   - **로컬 LLM**: PC에서 실행 중인 Ollama · LM Studio 등 OpenAI 호환 서버 주소와 모델을 입력합니다.
3. `웹브로셔 생성` → 미리보기 확인 → `HTML 저장` / `PPT 생성 (16:9)`.

LLM은 요구사항을 분석해 다음을 템플릿에 채웁니다.

- 요구사항 요약, 목표 · 타겟 · KPI (원문에 있는 수치만 사용)
- 요구사항별 닥터빌 대응 방안 · 활용 상품 (Insight 섹션 / 슬라이드)
- 서비스 추천 (옵션), 제목 · 제안 배경 · 서비스별 맞춤 포인트 · 진행 프로세스 문구

수치·실적·단가는 템플릿에 고정된 원문 데이터만 쓰며, LLM이 새로 만들지 않도록 지시합니다.

## API 키 보안

- 키는 이 저장소·HTML 파일·저장하는 제안서 어디에도 들어가지 않습니다.
- 입력한 키는 사용하는 브라우저에서만 쓰이고, `이 브라우저에 설정 기억`을 켰을 때만 그 브라우저(localStorage)에 저장됩니다. 공용 PC에서는 켜지 마세요.
- 요청은 브라우저에서 선택한 LLM(Anthropic API 또는 내 PC의 로컬 LLM)으로 직접 전송됩니다.

## 로컬 LLM 설정 (Ollama 예시, Windows)

1. https://ollama.com 에서 설치 후 모델 받기 (한국어가 되는 모델 권장, 14B 이상 추천)
   ```
   ollama pull qwen3:14b
   ```
2. 이 사이트에서 접속할 수 있게 CORS 허용 후 Ollama 재시작
   ```
   setx OLLAMA_ORIGINS "https://doctorville.github.io"
   ```
   (작업 표시줄의 Ollama 종료 → 다시 실행)
3. 사이트에서 엔진을 `로컬 LLM`, 주소 `http://localhost:11434/v1`로 두고 `연결 확인`.
   브라우저가 "로컬 네트워크 접근" 허용을 물으면 허용합니다.

LM Studio는 Developer 탭에서 서버를 켜고 CORS를 허용한 뒤 주소 `http://localhost:1234/v1`을 씁니다.
로컬 모델은 PC 성능에 따라 1~5분 걸릴 수 있고, 작은 모델은 결과 형식이 깨질 수 있습니다.

## 주의

- 이 저장소는 공개(Public)입니다. 광고 단가표·회원 통계가 소스에 포함되어 있습니다.
- 계약 조건, 내부 전략, 개인정보가 담긴 요구사항 원문은 사내 지침에 따라 팀장·사업부장 승인 후 입력하세요.
- 광고 단가가 포함된 제안서는 외부 발송 전 승인을 받으세요.

## 수정 방법

`index.html` 한 파일로 구성됩니다. 회원 수 등 기준 데이터는 파일 안의 `SOURCE`, 서비스 설명은 `SERVICES`,
광고 상품·단가는 `ADS` · `SEMINAR` · `PRICE` 상수를 고치면 됩니다. `main` 브랜치에 커밋하면 GitHub Pages에 자동 반영됩니다.
